## Notes

These files are static HTML with no tracking, no scripts, and no external requests. They are generated from the Markdown sources maintained in the main Alchohalt project (`docs/legal/*.md`), converted to the static pages above. To update a policy, edit the canonical Markdown, regenerate the corresponding `.html` file, and push to `main`; GitHub Pages redeploys automatically.

**Effective dates** are owner placeholders (`[OWNER: set at submission]`) — fill in the launch date before submission.
